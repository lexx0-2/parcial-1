Cómo se resuelve este tipo de ejercicio

{% if number == 7 %}
  1. Elegir u y dv: aplica LIATE como orientación; prioriza logarítmicas, inversas trigonométricas, algebraicas, trigonométricas y exponenciales.
  2. Derivar e integrar: calcula du = u′ dx y v = ∫dv.
  3. Aplicar la identidad: sustituye en ∫u dv = uv − ∫v du.
  4. Resolver la integral restante: simplifica y vuelve a aplicar partes si hace falta.
  5. Comprobar: deriva el resultado y verifica que recuperas el integrando.
{% elif number == 8 %}
  1. Verificar la forma: confirma que el integrando es P(x)/Q(x).
  2. Comparar grados: si grado(P) ≥ grado(Q), realiza división polinómica.
  3. Factorizar el denominador: identifica factores lineales, repetidos o cuadráticos irreducibles.
  4. Plantear fracciones parciales: asigna constantes a cada factor y determina sus valores.
  5. Integrar cada término: usa logaritmos, potencias o arctangentes y comprueba derivando.
{% elif number == 9 %}
  1. Identificar los radicales: reconoce raíces y expresiones con potencias fraccionarias.
  2. Reescribir: convierte √[n](xᵐ) en x^(m/n) cuando convenga.
  3. Elegir sustitución: por ejemplo t = √x si aparecen potencias pares de √x.
  4. Transformar toda la integral: reemplaza x y dx, sin dejar variables mezcladas.
  5. Integrar y regresar: expresa el resultado en la variable original y verifica.
{% elif number == 10 %}
  1. Identificar potencias: observa si los exponentes de seno o coseno son pares o impares.
  2. Separar un factor: si una potencia es impar, reserva un seno o coseno y convierte el resto con identidades.
  3. Aplicar identidades: usa sen²x + cos²x = 1 o 1 + tan²x = sec²x.
  4. Sustituir: toma u = cos x, u = sen x o u = tan x según el factor diferencial disponible.
  5. Integrar y comprobar: vuelve a x y deriva el resultado.
{% elif number == 11 %}
  1. Reconocer el radical: a² − x², a² + x² o x² − a².
  2. Elegir sustitución: x = a sen θ, x = a tan θ o x = a sec θ, respectivamente.
  3. Derivar: calcula dx y sustituye el radical con una identidad trigonométrica.
  4. Integrar en θ: simplifica la expresión y resuelve la integral trigonométrica.
  5. Regresar a x: dibuja el triángulo de referencia y expresa el resultado en x.
{% elif number == 12 %}
  1. Identificar la forma: busca una función racional de sen x y cos x.
  2. Definir t: usa t = tan(x/2).
  3. Transformar: reemplaza sen x, cos x y dx por sus expresiones racionales en t.
  4. Integrar: simplifica hasta obtener una función racional de t y resuélvela.
  5. Deshacer el cambio: sustituye t = tan(x/2) y comprueba derivando.
{% elif number == 13 %}
  1. Identificar la sección: determina la forma de cada corte perpendicular al eje x.
  2. Expresar sus dimensiones: lado, diámetro o radio en función de x.
  3. Calcular el área: cuadrado s², semicírculo πd²/8 o triángulo equilátero √3s²/4.
  4. Plantear el volumen: integra A(x) entre los límites dados.
  5. Evaluar: calcula la integral y expresa el resultado en unidades cúbicas.
{% else %}
  1. Dibujar la región: identifica la curva, el eje de giro y los límites.
  2. Elegir el método: discos, arandelas o capas cilíndricas según el corte.
  3. Definir radios o altura: expresa las dimensiones en función de x.
  4. Construir el integrando: π(R² − r²) para arandelas o 2π·radio·altura para capas.
  5. Integrar: evalúa entre los límites y reporta unidades cúbicas.
{% endif %}
