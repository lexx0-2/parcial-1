Integración por partes

Elige u (por ejemplo con LIATE), calcula du, integra dv para obtener v y aplica la identidad. Ejemplo: ∫xeˣdx = xeˣ − eˣ + C.

\\[\(\int u\,dv=uv-\int v\,du\)\\]

El solucionador utiliza SymPy para obtener primitivas simbólicas y evaluar integrales definidas. Si una integral no tiene primitiva elemental, puede expresarse mediante funciones especiales.

Calculadora interactiva

Introduce una función y pulsa calcular.

Ejemplos resueltos

Ejemplo 1. ∫xeˣdx: u=x, dv=eˣdx; du=dx, v=eˣ. Resultado: xeˣ−eˣ+C.
Ejemplo 2. ∫x cos(x)dx: u=x, dv=cos(x)dx. Resultado: x sen(x)+cos(x)+C.
